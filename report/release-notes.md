# EDGE / 01 — Digital engineering demonstrator

This release provides a reviewable compact enclosure study with editable CAD, genuine STEP/STL exports, manufacturing plans and executed digital checks.

- Eight-page engineering report, one-page portfolio summary and five-sheet drawing package.
- Parametric CadQuery source plus an unexecuted OpenSCAD companion.
- 31 component STEP/STL pairs checked; passive and optional-fan STEP assemblies.
- 31 passing tests and 361 nominal solid-pair intersection checks with no unintended overlap.
- CNC setup plan, printing plan, tolerance/inspection package, 3-2-1 fixture and thermal sensitivity analysis.
- Application email draft, five-minute walkthrough and empty physical-test log templates.

The passive cooling hypothesis exceeds the 80°C screening target at assumed 8 W /35°C ambient. Forced airflow is promising only under the assumed resistance; physical validation remains necessary. No machining, printing, measured thermal performance or CAM verification is claimed. This is an independent demonstrator, not an official comma.ai design.

Start with portfolio-summary.pdf, then engineering-report.pdf. The ZIP includes the source, exports and documentation; see README.md for regeneration commands.
